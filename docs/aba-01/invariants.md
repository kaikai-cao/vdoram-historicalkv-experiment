# ABA-01 阶段 B：Bubble Sort 控制流不变量

**范围**：程序级静态推导，基于 `source_semantics.md` 的固定 commit 证据。
**外部输入约束（本阶段明确假设，当前电路未保证）**：`1 ≤ n ≤ Nmax`，`Nmax < p`，`R15 = 1`。
**记号**：`n` = PC1 读入的初始 R1；`R8 = n`（PC9 复制后不再改写）；`R6` = 交换计数；`m` = 已完成的“有交换”外层轮数；当前 `R1 = n − m`。

---

## 0. 控制流图（CFG）

```
0 → 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 ─┐(R0<R1)          输入初始化循环
                  └──────────────────┘
9 → 10 → 11 → 12 → 13 → 14 ─┐(R3≥R1:退出内层→29)
                    ↓(R3<R1)
       15 →16→17→18→19→20 ─┬─(R5≥R4)→26
                            └─(R5<R4)→21→22→23→24→25→26
       26→27→28 ─┐(无条件回边→12)                 排序内层循环
29 →30→31 ─┬─(R6=0)→35
            └─(R6>0)→32→33→34 ─┐(无条件回边→10)  排序外层循环
35 →36→37→38→39→40→41 ─┐(R0<R8)                    输出循环
                  └────┘
42 Halt
```

回边：8→3、28→12、34→10、41→36。所有分支均来自 `JumpIfZero`（PC14 守卫是 `JumpIfZero(R4,29)`，R4 = bool(R3<R1)，故 R4=0 ⇔ R3≥R1）。

---

## B1. 输入初始化循环（PC3–PC8）

**建立位置**：PC2 `Set R0,0` 建立 `R0 = 0`。

**不变量 I1**（循环头 PC3）：`0 ≤ R0 ≤ n`，且 `mem[0..R0−1]` 已写入对应私有输入。

**保持条件**：
- PC4 在地址 `R0` 处 Store（地址线 = R0，源语义 §4.1）。
- PC5 `Add R0,R0,R15` 使 `R0 := R0 + 1`；由 I1 的上界 `R0 ≤ n−1`（守卫通过时）得新值 `≤ n`，且 `n < p` 保证无回绕。
- PC6–PC8：若 `bool(R0 < n)` 为真则 Not 后 R2=0，`JumpIfZero` 跳回 PC3；否则 R2=1，顺序离开。

**退出条件**：PC8 不跳转，即 `¬(R0 < n)`，在规范整数解释下 `R0 ≥ n`；结合 I1 得 `R0 = n`。

**依赖的指令语义**：`Set`（常量写入）、`Add`（mod p）、`PrivateInput`（只取下一个私有 Field，不约束值）、`LessThan`（253 位规范表示比较）、`Not`（假定输入布尔）、`JumpIfZero`（FieldNorm + SelectCompose）、`Store`（地址取 R0）。

**依赖的输入约束**：`n ≥ 1`（否则 Store 地址 0 不在 `[0,n−1]`）、`n < p`（R0+1 无回绕）。

**证明结论**：对 `n ≥ 1`，每次 PC4 执行时 `0 ≤ R0 ≤ n−1`，即 `mem[R0]` 地址属于 `[0,n−1]`。
**适用范围**：仅当 `n ≥ 1` 且比较为规范整数比较。`n=0` 时该结论**不成立**（见 B4）。

---

## B2. 排序循环（外层 PC10–34 / 内层 PC12–28）

### B2.1 外层不变量 I2（头 PC10）

`R2 = 0`，`1 ≤ R1 ≤ n`，`R6 ≥ 0`，`R15 = 1`，`R8 = n`。

**建立位置**：PC9 `Move R8,1`（R8=n）；PC10 `Set R2,0`；PC11 `Set R6,0`；进入外层前由 B1 得 R1=n。

**保持条件**：
- 内层结束后 PC29–31：`R0 = bool(0 < R6)`。若 `R6 = 0` 直接去 PC35，外层结束；若 `R6 > 0`，PC32 `R1 := R1 − 1`，PC33–34 无条件回 PC10。
- **R1 下界**：R6 只在 PC25（交换分支）递增。能到达 PC25 的任一内层迭代必满足 PC13 守卫 `R3 < R1`，且 `R3 = R2+1 ≥ 1`（因 I3 的 `R2 ≥ 0`），故该时刻 `R1 ≥ 2`。R1 在一轮外层内不递减（PC32 只在轮末），所以 PC32 处 `R1 ≥ 2`，`R1 − 1 ≥ 1`。若本轮无交换则 R6=0，不执行 PC32。故 `R1 ≥ 1` 恒成立，**mod p 减法不发生下溢**。
- **R1 上界**：R1 只减不增，故 `R1 ≤ n` 恒成立。
- R6 只增不减，故 `R6 ≥ 0` 恒成立；R2 在 PC10 重置为 0。

**退出条件**：PC31 不跳转 ⇔ `¬(0 < R6)` ⇔ `R6 = 0`（规范整数比较），进入 PC35。

**依赖的输入约束**：`n ≥ 1`；`n < p`；`R6 < p`（否则 PC25 计数器 mod p 回绕会破坏“R6>0 ⇔ 有交换”的语义）。

### B2.2 内层不变量 I3（头 PC12）

`0 ≤ R2 < R3 ≤ R1 ≤ n`，且 `R3 = R2 + 1`。

**建立位置**：PC10 `R2 = 0`；PC12 `Add R3,R2,R15` 建立 `R3 = R2+1`，此时 `R3 = 1`；若 `R1 ≥ 1` 则 `R3 ≤ R1` 或守卫立即失败（不会发生内存访问）。

**保持条件（含两条分支）**：
- PC13 `R4 = bool(R3 < R1)`，PC14 `JumpIfZero(R4,29)`。只有 `R3 < R1` 时进入访存体，于是 `R3 ≤ R1−1 ≤ n−1`，且 `R2 = R3−1 ≤ n−2`。
- PC15–18：`Move R0,R2` → Load mem[R2]；`Move R0,R3` → Load mem[R3]。两地址均在 `[0,n−1]`。
- PC19–20：`R7 = bool(R5 < R4)`。
  - **不交换分支**（R7=0，跳 PC26）：不写内存、不改 R6。
  - **交换分支**（R7=1）：PC21–24 以同一 `R0=R2` / `R0=R3` 写回，PC25 `R6 := R6+1`。**分支中没有重新计算地址**，地址仍受 PC13 守卫约束。
- 合并点 PC26 `R2 := R3`（旧值），PC27 `R0 = 0`，PC28 无条件回 PC12；PC12 重算 `R3 = R2+1`。故下一次迭代的 `R2 < R3` 仍成立，且 `R3 ≤ R1` 由 PC13 再次守卫（R1 在本轮内不变）。

**退出条件**：PC14 跳转 ⇔ `¬(R3 < R1)` ⇔ `R3 ≥ R1`；结合 `R3 = R2+1` 得 `R2 ≥ R1−1`，内层结束。

**依赖的指令语义**：Move/Add/LessThan/JumpIfZero/Load/Store（见 B1）；交换分支的 `LessThan` 结果布尔性。

**依赖的输入约束**：`n ≥ 1`；`n < p`；`R1 ≥ 1`（由 I2）；`R6 < p`。

**证明结论**：任一内层内存访问（PC16/18/22/24）时，`0 ≤ R2 < R3 ≤ R1−1 ≤ n−1`，故地址 `R0 ∈ [0,n−1]`。**对交换与不交换两条路径同时成立**。

---

## B3. 输出循环（PC35–PC41）

**建立位置**：PC35 `Set R0,0`。

**不变量 I4**（循环头 PC36）：`0 ≤ R0 ≤ n`，`R8 = n`，且 `mem[0..R0−1]` 已公开输出。

**保持条件**：PC36 在地址 R0 处 Load；PC37 PublicOutput；PC38 `R0 := R0+1`（由守卫 `R0 ≤ n−1` 得新值 `≤ n < p`，无回绕）；PC39–41 以 `R0 < R8 = n` 为继续条件。

**退出条件**：PC41 不跳转 ⇔ `¬(R0 < n)` ⇔ `R0 = n`。

**依赖的指令语义**：Set/Load/PublicOutput/Add/LessThan/Not/JumpIfZero。

**依赖的输入约束**：`R8 = n` 且 R8 在 PC9 之后不再改写（源码核对：全程序仅 PC9 写 R8）；`n < p`。

**证明结论**：PC36 每次执行时 `0 ≤ R0 ≤ n−1 ⊆ [0,Nmax−1]`。

---

## B4. 边界条件逐项处理

| 情形 | 程序行为（源码事实） | 地址域命题 |
| --- | --- | --- |
| `n = 0` | PC4 仍 Store `mem[0]`（守卫在 PC6 之后）；PC36 仍 Load `mem[0]` 并输出 | **不成立**：`[0,−1]=∅`，却访问地址 0。不能假设程序正确；证书必须 FAIL/UNKNOWN |
| `n = 1` | 输入写 mem[0]；PC12 R3=1，PC13 `1<1` 为假 → 内层零次访存；输出读 mem[0] | 成立：两次访问地址均为 0 ∈ [0,0] |
| `n = Nmax` | 所有地址 ≤ n−1 = Nmax−1 | 成立，前提是 `Nmax < p` 且 `Nmax² < p`（R6 计数不回绕） |
| `n > Nmax` | 源码无约束，程序照常运行并访问 `[0,n−1]` | **证书 FAIL**：违反外部输入约束；不能靠模拟“恰好没越界”放行 |
| 输入循环最后一次迭代 | 地址 `R0 = n−1`，PC5 后 `R0 = n`，PC6 `n<n` 为假退出；R0=n 未被用作地址 | 成立 |
| 输出循环最后一次迭代 | 地址 `R0 = n−1`，PC38 后 `R0 = n`，PC39 `n<n` 为假退出 | 成立 |
| PC19 比较为真（交换） | PC22/24 地址仍为 PC15/17 已守卫的 R2/R3 | 成立，无新地址计算 |
| PC19 比较为假（不交换） | 跳 PC26，无 Store | 成立 |
| PC13 比较为假（内层立即退出） | 不进入任何 Load/Store；PC29 继续外层或退出 | 成立（空访问集） |
| PC31 比较为假（无交换轮） | PC32 不执行，R1 不减 | 保持 I2 |

---

## 结论与适用范围

在外部约束 `1 ≤ n ≤ Nmax`、`Nmax < p`、`Nmax² < p`（保守）下，程序级静态推导可证：全部 6 条 Load/Store（PC 4/16/18/22/24/36）执行时地址 `R0 ∈ [0,n−1] ⊆ [0,Nmax−1] < p`。

该结论是**程序级不变量推导**，不证明：
- `n ≤ Nmax` 已由电路约束（源码明确没有）；
- LessThan 的位分解在 R1CS 中逐门正确（见 `field_soundness.md`）；
- 证书约束已接入真实执行关系（见 `certificate_format.md` 与 `decision.md`）。
