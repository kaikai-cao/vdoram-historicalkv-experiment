## B0. 撤回上一轮的 `PREFIX(t)=t`

correction 轮 A1.1 把“两值前 t 位相等”记为 `t µ`；A2.9 据此写 `R·L(L+1)/2 µ`。该数**只覆盖了逐位相等标志**，漏掉：

- 每位 XOR 的乘法实现（`b+d−2bd`）；
- t 个相等标志的 AND 聚合（t−1 次乘法）；
- 与 `valid` 的组合；
- 与已选槽 exclusion 的组合；
- one-hot/bit 约束；
- 无候选时 dummy 的处理；
- 4 字段条件选择的完整候选域 `R+1`。

本轮撤回该计数，给出两种可复算实现和逐层数字。

---

## B1. 模型与变量

每层：`L` = 树深；`R=179` stash 槽；`Z=4` bucket 槽；深度 `t=1…L`（`t` 个前缀位）。

| 变量 | 含义 |
| --- | --- |
| `β_{s,k}` (`k=0…L−1`) | stash 槽 s 的 leaf label 位；`BIT(L)` 得到，`L µ/槽` |
| `d_k` | 访问 leaf 的路径位（来自 `BIT(L_0)` 或递归 `BIT(L_{j−1})`），已在他处计费 |
| `valid_s` | stash 槽有效位 |
| `P_{s,t}` | leaf 前 t 位与 `d_0…d_{t−1}` 全相等 |
| `ok_{s,t}` | `P_{s,t} ∧ valid_s`：该槽可 evict 到深度 t bucket |
| `u_{t,q,s}` | 深度 t 的前 `q−1` 个 bucket 槽尚未选走 stash 槽 s |
| `elig_{t,q,s}` | `ok_{s,t} ∧ u_{t,q,s}` |
| `sel_{t,q,s}` | one-hot 选择位（真实槽 s=1…R）；dummy 选择位 `sel_dummy` |
| `no_cand_{t,q}` | `∏_{s=1}^{R}(1−elig_{t,q,s})` |

`dummy` 槽字段恒为 `(0,0,0,0)`，永远可写，用于在无合法候选时填满 Z 个 bucket 槽。

## B2. 前缀相等电路：两种实现

### B2.1 朴素逐位比较 + AND 聚合（每层每槽）

对每个深度 `t` 独立做：

```
xor_{k}   = β_{s,k} + d_k − 2·β_{s,k}·d_k      k=0…t−1      → t µ
eq_{k}    = 1 − xor_{k}                                    → 0 µ（线性）
P_{s,t}   = ∏_{k=0}^{t−1} eq_{k}                           → t−1 µ
ok_{s,t}  = P_{s,t}·valid_s                                → 1 µ
```

单个 `(s,t)` 为 `t+(t−1)+1 = 2t µ`；`Σ_{t=1}^{L} 2t = L(L+1) µ/槽`，加 `BIT(L)=L µ/槽`：

```
µ_prefix_naive = R·[ L(L+2) ]   per layer
```

### B2.2 共享前缀链（本轮推荐计数）

`P_{s,0}=1`，逐层复用上一位结果：

```
BIT(L)                                                  → L µ/槽
xor_{k} = β_{s,k}+d_k−2β_{s,k}d_k        k=0…L−1        → L µ/槽
P_{s,t} = P_{s,t−1}·(1−xor_{t−1})        t=1…L          → L µ/槽
ok_{s,t}= P_{s,t}·valid_s                t=1…L          → L µ/槽
```

```
µ_prefix_shared = R·4L = 4RL   per layer
```

当 `L≥2` 时共享链不劣于朴素实现；`L=2` 两者相同（`L(L+2)=8=4L`）。本轮示例两层实现都列，主报价取共享链。

## B3. 候选选择：逐项约束与计数

对每个 `(t,q)`（`t=1…L`，`q=1…Z`）：

| # | 约束 | µ/层 | 说明 |
| --- | --- | --- | --- |
| 1 | `u_{t,1,s}=1`；`u_{t,q+1,s}=u_{t,q,s}(1−sel_{t,q,s})`，`q=1…Z−1` | `(Z−1)RL` | 排除已选槽；比成对 `Z(Z−1)/2` 口径便宜 |
| 2 | `elig_{t,q,s}=ok_{s,t}·u_{t,q,s}` | `ZRL` | eligibility gating |
| 3 | `sel_{t,q,s}(1−sel_{t,q,s})=0`（真实槽） | `ZRL` | one-hot 的 bit 部分；Σ 为线性约束 `λ` |
| 4 | `sel_{t,q,s}(1−elig_{t,q,s})=0` | `ZRL` | 不能选不合格槽 |
| 5 | `no_cand_{t,q}=∏_{s=1}^{R}(1−elig_{t,q,s})` | `≤ZRL` | 保守上界（实际 R−1 次乘法/槽） |
| 6 | `sel_dummy=no_cand_{t,q}`；`Σ_{s=1}^{R} sel_{t,q,s}=1−sel_dummy_{t,q}` | `0` | 线性；dummy 保证 bucket 槽总被填满 |
| 7 | `slot_{t,q}[f]=Σ_{s=1}^{R} sel_{t,q,s}·stash_s[f]`，`f∈{addr,val,leaf,valid}` | `4Z(R+1)L` | 4 字段 × (R+1) 候选，dummy 字段为 0 |

第 7 项的 `+1` 来自 dummy 候选；上一轮只按 `R` 个候选计，少算 `4ZL`。

### 选择操作数与字段数（口径核对）

- 前缀选择器数量：`R·L`（共享链下每槽每层一个最终 `ok`）；
- exclusion 选择器：`(Z−1)·R·L`；
- 候选选择：`Z·L·(R+1)` 个 one-hot 位 × 4 个字段；
- 这与“比较次数”`R·L²`（朴素）不是同一量，分别列在 `κ`/`σ`，不并入 `µ` 之外重复计数。

## B4. 每层公式

```
µ_evict(shared) = 4RL + (Z−1)RL + 4ZRL + 4Z(R+1)L
                = (9Z+3)·R·L + 4Z·L

µ_evict(naive)  = R·L(L+2) + (Z−1)RL + 4ZRL + 4Z(R+1)L
                = [L + 9Z + 1]·R·L + 4Z·L
```

`Z=4` 时：`shared = 39RL + 4L`，`naive = (L+37)RL + 4L`。

校验：`L=20` 时 naive = `57·179·20 + 320 = 204,380`；`L=2` 时 naive = `39·179·2 + 32 = 13,994`（与 shared 相同，因 `L(L+2)=4L` 仅在 `L=2` 成立）。

## B6. 成本口径与防重复计数

| 符号 | 含义 | 是否计入 µ |
| --- | --- | --- |
| `µ` | 非线性乘法约束；`x⁷` 的 4 次乘法已含在 `H(k)=260k` | 是 |
| `β` | bit 约束 `b(1−b)=0`，每次 1 个 `µ` | **已含在 `BIT(L)` 与选择位 bit 中，不再另加** |
| `κ` | 比较/相等次数（如朴素前缀 `R·L²`） | 否，仅描述 |
| `σ` | 秘密选择的操作数/字段数（选择器 × 字段） | 否，其 `FieldMul` 已在 `SEL` 项计入 |
| `λ` | 线性等式（Σsel=1、root 绑定、`in_mem_val`） | 否 |

`BoolAndGadget` 源码（固定 commit，blob `0bf09fdb…`）确认为 `FieldMulGadget`，AND 按其输入数计乘法；`SelectComposeGadget`（blob `dc19cb7a…`）每候选每字段一次 `FieldMul`。因此上表以“1 个乘法门 = 1 µ”计，不含后端 auxiliary 约束倍率（UNKNOWN，沿用上轮 A5）。

## B7. 结论

- 撤回 `PREFIX(t)=t` 与上一轮 eviction 计数 `659,615`。
- 推荐 `shared` 公式 `(9Z+3)RL+4ZL`，示例十层合计 **769,670 µ**；朴素实现十层 1,005,950 µ，显式列出以免漏项。
- 逐层公式可独立复算；总成本 **2,635,246 µ/步**（含 C3 nonce 为 **2,697,766 µ/步**）。
- 本轮修正为约束完整性修正，**不是性能改善**；数字较上轮上升。没有发现需要改 ORAM 参数才能成立的项。
