# EXP-DORAM-08-R1-C1：交叉条件推导与数值例子

> 全部为符号推导的秘密乘法计数，不是 MPC 实测、不是经验阈值反推。
> 参数沿用 R1 源码推导值：`c_eq=389`、`c_sel=1`、`c_upd_shared=2`、`c_upd_separate=391`。

---

## 0. 记号与固定成本

| 符号 | 含义 | 默认 |
| --- | --- | --- |
| `T` | 执行步数（step `0..T−1`） | — |
| `n` | 固定地址域槽位数 | — |
| `K` | `c_eq + c_sel + lowbit_not + lowbit_and` | `393` |
| `b` | `lowbit_and`（E0/E1-A fetch 的负常数项系数） | `2` |
| `A0` | `C_E0(T) = K·T(T−1)/2 − b·(T−1)` | `393T(T−1)/2 − 2(T−1)` |
| `F_E0(s)` | `393s − 2` | 每步可见历史 `s` 行 |
| `F_A(n)` | `393n − 2 = K·n − b` | E1-A 每 Fetch（含 LowBit） |
| `F_B(n)` | `390n = (c_eq+c_sel)·n` | E1-B 每 Fetch（无 LowBit） |
| `w0` | step 0 是否为 STORE（0/1） | — |
| `wpos` | step > 0 的 STORE 数 | — |
| `u_pos` | 每个 step>0 STORE 的每槽更新乘数 | `2`（shared）或 `391`（separate） |
| `U` | `w0·c_upd_separate + wpos·u_pos` | 每槽更新乘数之和 |

统一总成本（历史追加 `T·append_mults` 三模型相同，默认 `append_mults=0`，不影响胜负）：

```
C_E0(T)      = A0
C_E1X(T,n)   = (T−1)·F_X(n) + n·U + T·append_mults      (X ∈ {A,B})
```

---

## 1. E0 vs E1-A（只读）

`U=0`，`T>1`：

```
(T−1)(393n − 2) < 393T(T−1)/2 − 2(T−1)
⟺ 393n(T−1) − 2(T−1) < 393T(T−1)/2 − 2(T−1)
⟺ 393n(T−1) < 393T(T−1)/2
⟺ n < T/2
```

**结论：E1-A 只读优势区间为 `n < T/2`；`n = T/2` 恰好相等；`n > T/2` E0 更便宜。**
关键点是 `−2(T−1)` 两边完全抵消——这正是 R1 代码实现漏掉、C1 修正的地方。

## 2. E0 vs E1-B（只读）

```
390n(T−1) < 393T(T−1)/2 − 2(T−1)
⟺ n < [393T(T−1)/2 − 2(T−1)] / [390(T−1)]
⟺ n < (393T − 4)/780
```

**结论：E1-B 只读优势区间为 `n < (393T−4)/780 ≈ 0.5038T`。**
比 E1-A 的 `0.5T` 略宽（`+4/780≈0.0051` 的截距差），因为 E1-B 每槽省掉 LowBit 的 `3n−2`。

## 3. E0 vs E1-A（读写混合）

带入 `F_A(n)=393n−2`，`U` 按 STORE 位置拆分（step 0 强制 separate）：

```
(T−1)(393n − 2) + n·U < A0
⟺ n·[393(T−1) + U] < A0 + 2(T−1) = 393T(T−1)/2
⟺ n < 393T(T−1)/2 / [393(T−1) + U]
```

其中 `U = w0·391 + wpos·(2 或 391)`。

- 全 `shared`（step 0 仍为 391）：`U = 391 + 2·wpos`，阈值略低于 `T/2`；
- 全 `separate`：`U = 391·(w0+wpos)`，阈值显著下降；
- 无 STORE：退化为第 1 节 `n < T/2`。

## 4. E0 vs E1-B（读写混合）

`F_B(n)=390n` 无常数项，E0 的 `−2(T−1)` 不被抵消：

```
390n(T−1) + n·U < A0
⟺ n·[390(T−1) + U] < A0 = 393T(T−1)/2 − 2(T−1)
⟺ n < [393T(T−1)/2 − 2(T−1)] / [390(T−1) + U]
```

`U` 定义同上。无 STORE 时退化为第 2 节 `(393T−4)/780`。

**以上为参数化不等式，不强行化成单一经验阈值；`T/n≈4` 只是 R1 采样网格上的充分条件，不是理论边界。**

## 5. 数值例子

### 5.1 只读，`T=64`（`A0 = 792162`）

| n | E1-A 成本 | E1-A 比值 | E1-B 成本 | E1-B 比值 | 胜负 |
| --- | --- | --- | --- | --- | --- |
| 16 | 396018 | 0.4999 | 393120 | 0.4963 | 两者都胜 |
| 31 | 767403 | 0.9687 | 761670 | 0.9615 | 两者都胜 |
| **32** | **792162** | **1.0000** | 786240 | 0.9925 | **E1-A 恰好相等；E1-B 仍胜** |
| 33 | 816921 | 1.0313 | 810810 | 1.0235 | 两者都败 |
| 64 | 1584450 | 2.0002 | 1572480 | 1.9850 | 两者都败 |

阈值核对：E1-A `T/2 = 32`（表中 n=32 精确 TIE）；E1-B `(393·64−4)/780 = 32.2410`（n=32 胜、n=33 败）。

### 5.2 读写混合，`T=128`，100% STORE（`A0 = 3194050`）

| 变体 / 更新模式 | 阈值 n | n=32 比值 | n=64 比值 |
| --- | --- | --- | --- |
| E1-A shared | 63.183 | 0.5064（胜） | 1.0129（败） |
| E1-A separate | 31.956 | 1.0014（败） | 2.0028（败） |
| E1-B shared | 63.658 | 0.5027（胜） | 1.0054（败） |
| E1-B separate | 32.076 | 0.9976（胜） | 1.9953（败） |

**观察**：`separate` 更新使 E1-A 阈值从 `63.183` 降到 `31.956`（约减半），E1-B 从 `63.658` 降到 `32.076`。这印证 R1-3 的结论：能否复用本步 eq 比较结果对总成本影响巨大；`c_upd_separate=391` 与 `c_eq=389` 同量级，使"独立更新一次"几乎等于"重做一遍全地址比较"。

### 5.3 STORE 位置对阈值的影响（`T=128`，E1-A shared）

| STORE 位置策略 | `U` | 阈值 n |
| --- | --- | --- |
| 无 STORE | 0 | 64.000 |
| 仅 step 0 | 391 | 63.503 |
| step 1..127（127 个 shared） | `127×2 = 254` | 63.676 |

**结论**：读写混合的优势边界**确实依赖 STORE 位置**。单个 step 0 STORE 的冲击（`-0.497`）大于 127 个 step>0 shared STORE 的合计冲击（`-0.324`），因为 step 0 无法复用 eq，强制 `c_upd_separate=391`。因此交叉条件必须显式携带 `w0` 与 `wpos`，不能把只读阈值直接套用到读写混合场景。
